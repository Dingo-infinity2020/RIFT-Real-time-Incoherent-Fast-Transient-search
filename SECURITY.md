# Security policy

This repository is a CPU/fake-data reference library. It does not accept
credentials, connect to acquisition systems, control processes, or contain
observation data.

Do not post credentials, private keys, personal data, or operational endpoints
in issues or pull requests. For a suspected security issue, use the private
security-reporting mechanism provided by the hosting service or contact the
repository maintainers privately before disclosure.

Reports must include a minimal reproducible example and must not include live
receiver data. A security report is not authorization to run hardware or live
acquisition code.
